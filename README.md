# 🎓 Hello-GitHub: GitHub Workshop Series

> 📖 [日本語版 / Japanese](README.ja.md)

A hands-on workshop series to learn GitHub from basics to practice.  
This repository contains a 10-part learning program (one preparation module + 9 workshops) that covers GitHub from the basics through practical, hands-on workflows. Each workshop is designed to take 60 minutes and combines a short lecture with hands-on exercises.  
Both **Windows** and **Mac** instructions are included in all materials.

## 🚀 Prerequisites

Please prepare the following before the workshop:

1. **GitHub Account** — Create at [github.com](https://github.com)
2. **Git** — Install from [git-scm.com](https://git-scm.com)
3. **Text Editor** — VS Code recommended: [code.visualstudio.com](https://code.visualstudio.com)
