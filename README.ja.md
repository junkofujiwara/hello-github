# 🎓 Hello-GitHub: GitHubワークショップシリーズ

> 📖 [English version](README.md)

GitHubの基本から実践までを学ぶ、全10回（準備編＋ワークショップ9回）のハンズオン教材です。  
各ワークショップは約60分で構成されており、短い講義とハンズオン演習を組み合わせて学びます。  
すべての教材に **Windows** と **Mac** の両方の手順が含まれています。

## 🚀 事前準備

ワークショップを受ける前に以下を準備してください：

1. **GitHubアカウント** — [github.com](https://github.com) で作成
2. **Git** — [git-scm.com](https://git-scm.com) からインストール
3. **テキストエディタ** — VS Code 推奨：[code.visualstudio.com](https://code.visualstudio.com)
